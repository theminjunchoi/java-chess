### 움직임 구현

#### King

- [x] 현 위치에서 모든 방향으로 1칸씩
    - [x] 현 위치(a, b)에서 사방으로 1칸까지
        - (a + n, b), (a, b + n), n의 절댓값 1
    - [x] 현 위치(a, b)에서 모든 대각선으로 1칸까지
        - (a + n, b + m), 이때 n과 m의 절댓값은 1

#### Queen

- [ ] 현 위치에서 모든 방향으로 끝까지
    - [ ] 현 위치(a, b)에서 사방으로 끝까지
        - (a + n, b), (a, b + n)
        - n의 절댓값은 최대 7
    - [ ] 현 위치(a, b)에서 모든 대각선으로 끝까지
        - (a + n, b + m), 이때 n과 m의 절댓값 같음
        - n, m의 절댓값은 최대 7

#### Rook

- [x] 현 위치(a, b)에서 사방으로 끝까지
    - (a + n, b), (a, b + n)
    - n의 절댓값은 최대 7

#### Bishop

- [x] 현 위치(a, b)에서 모든 대각선으로 끝까지
    - (a + n, b + m), 이때 n과 m의 절댓값 같음
    - n, m의 절댓값은 최대 7

#### Knight

- [ ] position 차이
    - (2, 1), (-2, 1), (2, -1), (-2, -1)
    - (1, 2), (-1, 2), (1, -2), (-1, -2)

#### Pawn

- [x] 처음에만 두칸 전진, 나머지는 한 칸씩 전진
- [x] 잡을 때만 앞으로 대각선 한 칸
